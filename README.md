# Sobre o Projeto

O **Corre** é uma aplicação web desenvolvida para apoiar o controle financeiro de entregadores autônomos.

O projeto surgiu a partir da identificação de uma necessidade real apresentada por **Carlos**, entregador autônomo que relatou dificuldades para registrar ganhos, despesas e acompanhar o resultado financeiro de sua atividade ao longo do tempo.

A proposta consiste em disponibilizar uma solução simples, acessível e centralizada para acompanhamento financeiro diário, permitindo uma visão clara da operação e do lucro obtido.

---

# Contexto do Problema

Profissionais que atuam com entregas frequentemente realizam seus controles financeiros por meio de:

- anotações em papel;
- bloco de notas do celular;
- planilhas;
- registros informais;
- memória.

Esse cenário dificulta:

- acompanhamento das despesas operacionais;
- visualização do lucro real;
- análise dos resultados mensais;
- tomada de decisão baseada em dados.

A ausência de informações consolidadas reduz a capacidade de gestão financeira da atividade.

# Usuário e Necessidade

## Perfil do Usuário

**Carlos**

Entregador autônomo que realiza entregas diariamente utilizando motocicleta como principal ferramenta de trabalho.

## Necessidades Identificadas

- Registrar ganhos diários.
- Registrar despesas operacionais.
- Consultar histórico financeiro.
- Visualizar lucro diário.
- Visualizar lucro mensal.
- Centralizar informações em um único local.

---

# Objetivos

## Objetivo Geral

Desenvolver uma aplicação web para registro e acompanhamento financeiro de entregadores autônomos.

## Objetivos Específicos

- Centralizar informações financeiras.
- Facilitar o registro diário de movimentações.
- Disponibilizar consultas históricas.
- Apresentar indicadores financeiros básicos.
- Aplicar conceitos de banco de dados.
- Utilizar controle de versão durante todo o desenvolvimento.
